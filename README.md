# Sistema de Gestión Académica

Aplicación desarrollada en Java con interfaz gráfica Swing para la gestión de estudiantes, cursos y matrículas de una universidad.

## Funcionalidades

- Registrar, listar y gestionar estudiantes
- Crear y listar cursos
- Matricular estudiantes en cursos
- Registrar notas por curso o por estudiante
- Calcular promedio por matrícula

## Tecnologías

- Java
- Swing (interfaz gráfica)
